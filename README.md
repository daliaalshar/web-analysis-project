# 📊 King Fahad National Library

## Overview

This project analyzes the website performance of the **King Fahad National Library** using web analytics techniques. The analysis focuses on understanding user behavior, traffic sources, engagement, and website performance to provide actionable recommendations for improving the user experience and increasing visitor engagement.

## Objectives

* Analyze website traffic and user behavior.
* Measure key website performance indicators (KPIs).
* Identify the main traffic acquisition channels.
* Evaluate user engagement across website pages.
* Provide recommendations to improve website performance.

## Key Performance Indicators (KPIs)

* Total Users
* Total Sessions
* Total Page Views

## Analysis Performed

* Website traffic analysis
* Visitor acquisition analysis
* Source and medium analysis
* Landing page performance
* User behavior analysis
* Device usage analysis
* Engagement by traffic source
* Bounce rate analysis

## Key Findings

* The website attracted **86 users** and generated **91 sessions** during the reporting period.
* Direct traffic and social media (especially Snapchat and TikTok) were the main visitor sources.
* The **Register** page received the highest number of visits.
* Mobile devices accounted for the majority of website traffic.
* The registration page had a high bounce rate, indicating opportunities to improve the user experience.

## Recommendations

* Improve SEO to increase organic traffic.
* Optimize the website for mobile devices.
* Enhance the registration page to reduce bounce rate.
* Monitor traffic sources regularly.
* Continuously analyze visitor behavior to improve engagement.

## Tools Used

* Google Analytics 4 (GA4)
* Data visualization reports
